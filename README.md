# Řezy – plugin do CloudCompare

Řezy mračnem bodů a kreslení 2D výkresu nad nimi (výstup MicroStation V7).

Postaveno na CloudCompare 2.13.2. Sestavení pro Windows běží automaticky na GitHubu
(záložka **Actions** → poslední běh → **Artifacts** → `CloudCompare-Rezy`).

## Použití (verze 0.1)
1. Rozbalte zip a spusťte `CloudCompare.exe`.
2. Otevřete mračno (LAS), vyberte ho a v menu *Plugins* zvolte **Řezy**.
3. Vpravo se otevře panel *Řezy*: výška řezu, tloušťka (výchozí 10 cm), krok.
4. **PgUp / PgDn** posune řez nahoru / dolů.
